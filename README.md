## The pitch

> A chair that sinks one millimetre every time you slouch, until you are sitting on the floor with perfect posture.

One sentence, 113 characters: a ridiculous invention (a chair that sinks a millimetre per slouch) fixing a tiny everyday annoyance (slouching) — the punishment is the cure.

## How it works

`main.py` writes the pitch byte-exact to `/output/entry.txt`. No input, no network, no environment — the same sentence on every run.

```sh
python3 main.py
cat /output/entry.txt
```
